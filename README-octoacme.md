# OctoAcme Project Management Docs

## Project Management Process Summary
OctoAcme delivers projects through clear, iterative, and collaborative workflows. Key principles include:
- **Customer-first**: Focus on value and usability.
- **Iterative delivery**: Deliver small, testable increments.
- **Clear ownership**: Named PMs and Product Leads for each project.
- **Evidence-based decisions**: Measure and adapt.
- **Psychological safety**: Encourage feedback and learning.

Lifecycle steps:
1. **Initiation**: Define problem, goals, and stakeholders.
2. **Planning**: Prioritize work, estimate, and plan releases/milestones.
3. **Execution**: Track, build, test, review, iterate, escalate blockers appropriately.
4. **Release**: Follow standard deployment/release checklists and incident playbook.
5. **Retrospective**: Learn and feed improvements back into processes.

Roles covered: Product Manager, Project Manager, Developers, QA, Stakeholders — see docs for detailed responsibilities.
